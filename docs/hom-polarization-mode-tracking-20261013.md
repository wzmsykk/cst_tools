# HOM 极化模配对与网格收敛判定

## 本轮观察及判据

用户指定后处理相邻网格变化容差为5%，连续两次满足。测试对象是 `project/HOM analysis/HOM analysis_clean.cst`，不是 Pillbox。固定范围513.492631838138–713.492631838138 MHz、nmodes=2、关闭自适应、材料求值613.493 MHz。cell为每波长网格划分数，不是统一毫米尺寸。

cell=12→18 时频率变化较小，但两种R/Q特征互换；这与极化方向/编号变化相容，尚未通过场型证明二者属于同一模族。不能将近频率自动合并或删除为重复结果。

## 文献和官方实现依据

专用学术检索MCP未挂载，本次通过网页检索核查作者论文与官方实现文档；不是系统综述。

1. [BBU Limitations for ERLs，EPAC08 MOPC059](https://proceedings.jacow.org/e08/papers/mopc059.pdf)：用Pillbox凹陷和形变研究偶极模分裂，并用不同网格密度区分几何效应和网格效应。与本项目直接相关的是必须独立检验网格敏感性，不能仅凭两个频率接近确认极化对。
2. [EPAC06 THXFI01](https://proceedings.jacow.org/e06/PAPERS/THXFI01.PDF)：讨论三维耦合器导致的偶极模退简并，以及阻尼线宽重叠时的旋转/椭圆极化。真实开放有损模型不能一律按无损正交简并对处理。
3. [COMSOL官方：Tracking Eigenmodes over Parametric Sweeps](https://www.comsol.com/blogs/tracking-eigenmodes-over-parameteric-sweeps)：用归一化场重叠跟踪模式，避免频率排序变化导致模族标签交换。方法可借鉴，不意味着CST2022具有同名功能。
4. [Xiao等，arXiv:2603.13193v2](https://arxiv.org/abs/2603.13193v2)：保守弹性波导Hermitian特征值问题中，简并应使用旋转不变子空间跟踪。属于预印本，不能把其理论保证直接迁移到本项目复材料/有损CST算子。
5. [gprMax官方特征模端口理论](https://gprmax.readthedocs.io/en/latest/eigenmode_port_theory.html)：实现场重叠、SVD主角度、简并子空间对齐，并要求混合后的特征对残差有效；已分辨的真实分裂不允许任意旋转混合。自动跟踪仍标为实验性，参考其设计而非照搬阈值。

## 推荐的分层方法

### 1. 模式身份：场重叠而非编号

跨网格在同一物理采样点插值复数E/H场，使用正定采样权重进行归一化内积：

`MAC(a,b)=|aᴴ W b|²/[(aᴴ W a)(bᴴ W b)]`。

它不受整体相位和幅度影响。按完整重叠矩阵做一对一匹配，同时限制频率漂移；重叠不足或候选差异不足时标记身份未确认。积分权重/归一化必须适合有损色散问题，不能直接用复介电常数当正定范数。固定采样点低成本方案只是全体积重叠的近似。

### 2. 近简并：比较完整子空间

分别对旧/新模式组的加权场矩阵做QR/SVD正交化，再对 `Q_oldᴴ Q_new` 做SVD。最小奇异值平方衡量整个组中最差方向的重叠。这能区分“相同二维空间中的极化旋转”与“混入另一个模族”。不因为频差小就强制组对；需要场型、对称性和邻近谱支持。

### 3. 极化方向：用束流相关量定义

可在同一束流路径提取复横向踢电压分量，或多条等半径不同方位积分线上的复纵向电压，构建二阶极化矩阵并求主轴。仅有一个方向的R/Q模平方不能恢复复相位、极化角或椭圆极化。当前只保留R/Q标量，因此完整极化判定仍需新增复电压/场采样输出。

### 4. 收敛指标分开

- 原始数据：每mode频率、R/Q、Q、损耗和场型，不重写或丢弃。
- 同组频谱：中心频率 `(f1+f2)/2`、频差 `|f2-f1|`。频差可能趋于零，不能直接用其相对变化作为唯一判据；结合绝对分裂及中心频率归一化误差。
- 同一积分路径上的组R/Q总和：这里的“同一”只表示跨网格比较时固定束流轴、偏移量、积分长度和相位约定，**不是对积分位置不敏感**。在严格简并、完整且能量正交归一化的子空间及同一线性电压泛函下，正交基旋转不改变平方耦合总和；这只是固定泛函下的基变换性质，不是位置不变量。对已分裂、非正交或强有损模式只作诊断，不能无条件视为不变量。
- 对理想线性偶极极化，小偏移下单模耦合可示意为 `R/Q ∝ r² cos²(φ−θ)`；相差90°的另一极化对应 `r² sin²(φ−θ)`。同一偏轴位置可以对一个模式近零、对另一个模式接近该半径下最大值。0–1表示归一化方向权重，不是R/Q本身的物理范围。两者求和只有在理想对称、等耦合及合适归一化条件下才消去方位角，仍依赖半径和路径；真实不对称/已分裂模型不能直接套用。
- 因此必须保留每mode、每积分线的结果和位置元数据，不能用总和替代束流方向相关的单模风险。只有一条线上的R/Q无法区分极化旋转、编号交换及局部耦合变化；需要多个方位线的复电压或复场重叠，且记录相位。该项是对本项目的物理适用条件说明，不是当前已经验证的模族属性。
- 不把Q或损耗简单相加当旋转不变量；仍逐mode保留，或采用经物理验证的组响应模型。

5%是后处理工程验收容差，不是极化分裂判定阈值，也不保证BBU/窄带阻抗预测精度。必须明确基准是逐mode数值稳定，还是经身份验证的模族稳定。

## 计算策略

精确镜面对称的模型可按正确PEC/PMC对称边界分别求两种奇偶/极化分支，减少数值旋转与算量；耦合器、材料或边界破坏该对称时禁止强行施加。真实分裂的两个特征模保留各自频率，不将其线性组合冒充新的单频本征模。

最小下一步是固定点复场采样与两mode重叠矩阵；仅在近简并组中增加子空间判定。不要先做全场巨量导出或通用模态框架。
