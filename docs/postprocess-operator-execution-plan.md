# 后处理算子的端到端计算流程选择

更新：2026-10-13。依据：[CST场效率实测](cst-field-efficiency-acceptance-20261013.md)、[极化模跟踪设计](hom-polarization-mode-tracking-20261013.md)。本文件确定当前选择规则，不修改后端实现。

## 1. 优化目标：相同正确性约束下，总成本最低

对算子q选择流程r，比较：

`T(r,q) = 启动/打开 + 取场/加载 + 插值/采样 + 数据复制/转换 + 导出/传输/读取 + 算子计算 + 保存/收尾`。

只在计算定义、积分域、采样权重、精度和模式身份一致的候选间比较。先排除语义不正确的路线，再优化时间；不能用更少采样点或未加权求和冒充更快的同一积分。

实际调度时区分三种边界：

- Worker已持有本次结果：比较增量后处理时间，不重复启动CST。
- 离线只有原生结果：必须计入CST启动/加载，以及实际需要的副本建立和退出时间。
- 已有经过验收的导出场或小矩阵：优先复用，不重复取场导出。

原生导出本身已包含取场/插值，不能再次加独立VectorPlot3D采样时间。路线总时间采用每次完整链路计时后求中位数，不能把独立阶段的中位数相加当作实测总时间。

## 3. 按具体算子的流程选择

“当前首选”指已有证据支持或保留已验证实现；“候选”不是已证明的全局最优。

| 算子/需求 | 当前首选流程 | 准备成本与理由 | 证据/限制 |
|---|---|---|---|
|模式频率、已有Q/损耗等标量|语义一致的原生标量读取；不足时现有CST查询→小结果|不为一个标量导出3D场；已有结果可直接读取|版本、单位、结果类别必须一致；未请求的外部Q缺失不能当成整体失败|
|指定轴、偏移、路径的R/Q|保留现有CST运行时后处理→每mode每积分线标量|仅取所需路径和计算量，避免全场导出|物理算法已在原流程使用；效率路线未独立对比，不能宣称最快|
|单点/少量点的复E/H|CST批量采样→少量复分量输出|不按点重复COM调用，不导出全域|批量接口存在；小规模输出效率尚需专项验收|
|同原生网格的复点乘、数组范数|Result3D加载→显式Conjugate→DotProduct→小标量/矩阵|避开VBA数组复制和逐点循环|已实测；不是体积加权积分；算子修改调用对象|
|同原生网格的等权MAC|原生计算两个范数和交叉项→Python做标量归一化|复用已得到的范数；Python不需要场文件|底层求和已验收；网格及采样顺序必须相同|
|不同网格/快照的场重叠MAC|定义公共域/点/权重→CST原生HDF5→Python读取一次、转换一次、加权点乘|数据坐标可核对；复杂比较可离线复用|导出/计算效率已测；跨网格插值、全域积分精度尚未验收|

|极化方向、椭圆度及束流相关耦合|多方位同半径路径的复电压/复踢量→Python小矩阵分析|输出少量复数即可；不默认需要全场|复电压新增接口未验收；单线R/Q模平方不保留相位|

## 4. 各路线的关键约束

### 4.1 原生点乘：适合已对齐数据，不能省略数学定义

实测DotProduct执行普通复乘，不自动共轭。若目标为 `aᴴb`，先共轭a；对象被覆盖后不能用于另一组配对，必须重新加载或建立副本，其成本应计入。

同长度不是同网格的证明。使用原生索引直接比较时，必须验证网格、坐标/采样位置、分量顺序和域支持一致。跨网格禁止无条件点乘。

若需要正定加权内积 `aᴴWb`，必须正确处理W。原生点乘前将场预处理为 `sqrt(W)a` 是一种数学候选，但权重获取及转换开销未测试，不据此宣称当前原生接口已实现体积积分。

### 4.2 Python路线：节省计算时间，不重复支付准备成本

一次原生导出、一轮读取和复数组转换后复用同一场缓存完成多个算子。不得每个指标重复导出，也不得每个模式对重新读两个文件。HDF5正式数据、ASCII小样核对；禁用VBA逐行生成大CSV作为常规数据通道。

多模式场矩阵可能受内存限制，可分块累计Gram/交叉矩阵，不必持有完整 `N×m` 场矩阵。需要按预期最大N/m测量内存和I/O，不以本次两mode热缓存数据保证百万点或网络盘性能。

### 4.3 小矩阵分工：充分统计量比完整场更小

设两个模式组为A、B，使用同一正定内积得到：

`G_A=AᴴWA`、`G_B=BᴴWB`、`C=AᴴWB`。

单模MAC只需范数与交叉项；子空间比较可对有效秩内的G进行白化，再对 `G_A^(-1/2) C G_B^(-1/2)` 做SVD。Gram矩阵病态时截断/拒绝不可靠方向，不能直接求逆。秩阈值与匹配门限需独立验收。

如果CST能够低成本生成上述**正确加权**小矩阵，优先只传矩阵到Python；否则在公共场上用Python形成矩阵。当前DotProduct验证仅覆盖等权原生数组，不能据此保证跨网格G/C可用。

### 4.4 R/Q与极化：位置和方向不能合并抹平

保留每mode、每积分线、每偏移位置的结果。正交dipole极化在同一偏轴线上可能分别近零/最大；R/Q总和稳定不等于单模方向性稳定，也不代表位置不敏感。原始Mode编号、匹配标签和极化方向分别存储。

不能将已分裂的本征模随意混合成新的单频本征模。子空间对齐是模族比较工具，不能重写原始频率与物理后处理值。

## 5. 重复计算的摊销与缓存

比较多算子或多次分析时，使用批量总成本：

`T_batch(r)=P_shared(r)+Σ T_incremental(r,q)+收尾`。

不要将可复用准备成本P重复计入每个算子；也不要因缓存已命中就声称首次准备免费。选择策略按实际缓存状态计费。

缓存身份至少包括：结果快照/场源身份、mode与频率、E/H类别、坐标与单位、公共点集/域、权重/掩码、归一化约定和导出精度。仅用mode编号或工程文件名不足以识别结果。若比较几何变化，还需记录坐标映射。

E/H场在工程同名计算结果目录中。新求解仍只复制.cst；读取旧场必须让对应结果目录可访问，或由CST带结果另存。不因已有.cst就假定可缓存命中场数据。

## 6. 最小执行决策

1. 已有正确的小结果/矩阵：直接Python分析。
2. 有语义完全一致的原生标量/路径计算：复用现有CST流程。
3. 同原生网格等权场运算：CST原生算子，只输出小结果。
4. 跨网格或复杂场分析：公共点HDF5＋Python，复用一次准备的数据。
5. 正确性或身份未确认：报告未确认，不为了提速跳过插值、权重、共轭或极化检查。

“公共点批量采样→SetArray→原生DotProduct→小矩阵→Python”是下一项候选，可避开VBA循环与大文件，但尚未验收，不能替换已测路线。

## 7. 待验收清单

- 上述公共点原生累计候选与HDF5路线：同点、同权重、同精度比较。
- 全域采样密度与权重收敛；跨网格插值及边界无效点处理。
- 多方位复电压：位置/相位/归一化验收。
- 大量mode时加载复用、小矩阵批处理、分块矩阵乘法及峰值内存。
- 冷启动、冷缓存、独立任务完整墙钟；不要沿用热缓存结论。
- 共轭、对象被修改、近零耦合绝对误差、病态Gram和匹配歧义的回归测试。

当前结论是“在已测语义和规模下的优先流程”，不是所有算子、硬件和模型的全局最优证明。
