# HOM窄窗口单模式扫描

2026-11-03按AdaptiveHomScanner与HomScanAlgorithm核对；旧过程/原测试门禁见[快照](archive/20261103-semantic-review/hom-scan-algorithm.md)，新数值失败恢复细节见[策略](hom-solver-failure-recovery.md)。本页不把窄窗偏好表述为所有电磁模型的精度定理。

## 范围和推进

常规每次nmodes=1。fmin为起点、fmax是首个求解窗口上限、endfreq为扫描目标上限；不是两个同义上限。后续窗口宽度取初始窗口并最多50MHz，接受模式后从max(nextafter(f,+inf),f+frequency_abs_tol)继续，避免旧0.1MHz取整跳过近模。CST请求模式数不是保证返回数量。

窗口内首模须有Mode 1必需后处理、有限值和身份/快照。返回多个模式、低于下限或已采用频率明确拒绝；不能静默截断或去重后宣称完整。单模可能返回超过请求上限的频率：先保持下限扩窗并重算确认，不直接导入首次越界结果。确认频率超endfreq可正常结束，不把目标外模式写入汇总。

通用扫描回调显式空结果可表示已确认空区间；生产HOM的空后处理列表不是该契约，按结果缺失处理，Start=0/迭代耗尽也不能直接判空。已用模式数由边界条件和物理谱决定，不为凑数量扩大结果解释。

## 失败、缺口与恢复

每区间有有限尝试，全局max_solver_calls防无进展循环。普通区间尝试耗尽会记录failed/failure_reasons并向后扫描；结束仍有failed时HomScanAlgorithm记录HOM_SCAN_COMPLETED_WITH_GAPS并返回report，不能称完整覆盖。达到全局Solver调用预算时抛IncompleteScanError；不是“任意failed区间一律抛该异常”。用户停止持久pending并抛ScanInterrupted，不能将其当空区间。

生产failure_recovery开启：先临时加密一次，再原密度扩窗探测并窄窗确认。探测不是模式导入，判空只限明确策略/证据；未成功确认则保留缺口。常规任务不重复写cell，临时密度状态和恢复阶段落盘，详细语义与未完成真实门禁见恢复专题。

检查点v4保留policy/项目/PPS/快照身份、pending/failed/empty/completed、采用与恢复阶段；旧v3仅按限定规则补新增默认，不能忽略原身份。confirmed_frontier是连续确认位置，包括空窗；calculated_upper记录计算/探测最高窗口上界，二者都不能用最高已找到频率替代。单模窗口完成也不证明该窗口后续所有模式已枚举。

有检查点/manifest时不允许新运行从头覆盖，须显式恢复/继续；已确认结果不重复导入。失败新Worker从预处理基准启动，成功HOM快照接力是显式且同槽的。扫描目标/mesh/源/安装策略按现有清单核验，不因更改GUI文本绕过身份约束。

## 后处理和物理边界

常规PPS只处理Mode 1；_All不是“求解更多模式”的开关，不据名字假定其结果或模式数量。逐频HOM谱枚举与固定参考场匹配是不同任务，不能把不同频率模式的低MAC当漏扫或自动丢弃该模式。

严格简并/极化模式仅凭单模+频率右移无法证明全部找到；重复频率会保留失败原因，局部多模/子空间策略须另立门禁。R/Q依积分线位置/轴，退简并成员可以在同一偏轴线上出现极端差异；频率近或某一R/Q相同不能单独认证身份。

## 验证入口

算法、恢复、manifest、假Worker/检查点与GUI测试按功能索引选择；真实窄窗/密度恢复、简并检测、XYZ及复杂结构分别验收。原HOM中断真实记录不代替新增加密/探测策略实测。标准收尾为Save/回执/StopAck/批返回并核验进程，不在正在运行的宏页内Quit。
