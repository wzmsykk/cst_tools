# HOM 测试模型固定网格基准

## 结论

本频段工程回归测试采用 **cell=30**，对应本次92,706个四面体；cell=36保留为较细网格对照。依据是按R/Q特征临时配对的七项后处理连续两次变化低于用户指定5%，且36再次确认最大变化0.65%。这是标量特征稳定的工程基准，**不是场型已验证的逐物理模式收敛证明**。没有修改正式扫描默认配置或源工程。

## 固定条件

- 源模型：`project/HOM analysis/HOM analysis_clean.cst`，SHA256 `996b485dade2ddc4232aafc052c04314836a54fd74423fa7b0fbe819a975b967`。
- CST2022，513.492631838138–713.492631838138 MHz，nmodes=2，七项_All后处理。
- 每档从同一源.cst独立预处理，只复制.cst。通过历史块设置 `StepsPerWaveNear=cell`，关闭四面体自适应；材料求值频率均为613.493 MHz。二阶求解，精度1e-6，考虑损耗。
- cell是每波长划分数，不是统一毫米边长。模型局部细化和曲面设置保持原样，复现必须使用同一模型与求解范围。

临时配对方法是每档按轴上R/Q从小到大排序，将同一特征的全部指标对应比较。原始编号比较在18、30、36发生约55%、51%、51%的变化，因此不能宣称原始Mode编号序列收敛。频差36比30增大，也不能宣称真实分裂已收敛至零。配对规则有误认模式风险，后续需按复场MAC/子空间验证，参见 [极化模跟踪设计](hom-polarization-mode-tracking-20261013.md)。

30档的轴上R/Q总和2.843110377209769e-6，36档2.857621243590705e-6；这是固定积分路径的组耦合诊断，不是对位置不敏感的量，也不无条件称其为有损模型的不变量。相差90°的偶极极化在同一偏轴线上可以分别接近零和最大耦合；总和不能替代各模式的方向性结果。

补充限制：仅按一条线上的R/Q大小排序，不能区分真正编号交换与极化旋转。后者会连续重新分配两个模式的耦合，甚至改变排序，因此上述cell=30只能作为暂定的标量回归基准，不能据此认定极化方向相关后处理已经收敛。后续需多方位积分线/复场验证；不得把排序后的signature标签当作物理极化标签。
