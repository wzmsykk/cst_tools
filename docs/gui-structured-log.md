# GUI结构化运行事件

2026-10-14。现行入口为MainWindow.logTextBox（StructuredLogHandler），原日志Handler留作原始日志镜像。

## 使用

默认“运行事件”显示时间、级别、阶段/任务、摘要、状态五列。级别默认信息及以上，可切换警告、错误、全部含DEBUG；关键词搜索匹配消息/上下文，阶段和任务ID独立筛选，可组合。阶段筛选支持已知中文标签和原始代码。文本筛选150ms去抖。

点击事件，在下方查看消息、异常堆栈、源码文件/行/函数、record_id、run/session/task关联ID和诊断路径；“复制详情”复制当前内容。旧消息没有结构化字段仍显示为未分类，不从中文消息猜测成功/失败语义。预处理新增phase/action/target/before/after/status/diagnostics字段；其状态是原契约状态，不把日志返回当CST计算成功。

“自动滚动：开/关”为可切换按钮，每次打开GUI默认开启，同时控制事件表和原始日志。关闭后仍正常接收/回放日志，但不拉动当前阅读位置；重新开启立即返回最新并清除事件选中。即使开启，选中事件或向上滚动时仍暂时暂停跟随。“回到最新”只做一次跳转，不改自动滚动开关；关闭状态下跳转后继续保留手动阅读模式。拖动期间暂停追加。筛选不清除缓存。2026-10-15删除“清空日志”按钮及清空API，运行/恢复不主动清空记录；[自动恢复日志与状态](gui-log-restoration.md)仍保留有界显示性能。

“原始日志”标签保留最近5000行；“打开.log/打开JSONL”使用当前Logger真实配置或Runner明确提供的文件路径，不猜项目路径，没有对应来源则禁用；文件未创建或系统无法打开时显示提示。Runner历史日志自动有界分批回放，不一次读入巨大文件。

六链可读性重构后，实时“原始日志”标签仍为GUI格式化镜像，不是磁盘文件逐字副本；完整上下文与异常关联查看详情或打开文件。ContextLogger不再污染message，见[六链日志内容分工](readable-logging.md)。

默认文件路径现位于[可读运行目录](readable-log-directories.md)，GUI文件按钮仍读取真实handler路径，无需按run_id猜目录；总览在项目logs/index.md，摘要在对应目录summary.md。

## 性能与协议边界

QTableView+QAbstractTableModel按需绘制，固定行高、不自动按全部内容调整尺寸。事件队列最多2000条、缓存最多5000条，每批最多128条，后续间隔30ms；后台线程仅生成快照及排队，GUI线程更新模型。原始镜像沿用有界批量控件。过载省略旧界面记录并显示数量，完整log/JSONL是否存在取决于配置的文件handler。

消息与异常详情分别最多8192字符，最多32个扩展字段、每字段512字符；长消息/堆栈显示截断提示。保留字符串快照而非LogRecord/traceback对象，不占住任务堆栈。原始镜像另有4096字符显示限制。字段超长仅保留前512字符；原文件不截断。

只有明确CST_PROGRESS/WORKER_PROGRESS/CST_WAIT_PROGRESS事件，低于WARNING且run_id、session/session_id、task/task_id齐全，才按身份+phase+event更新同一行，计数累计。不同任务、无完整身份和所有警告/错误均保留独立事件。普通INFO不自动合并；显示模式不是新ABI，也不要求重写所有旧日志。

主窗口兼容保留logTextBox.widget原始控件供既有测试/调用使用，布局改用logTextBox.panel；文件日志配置不变。关闭后忽略排队回调并停止GUI定时器，避免Qt父控件销毁后的回调访问；不影响CST安全停止。
