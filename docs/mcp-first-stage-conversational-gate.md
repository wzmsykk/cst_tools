# 首阶段门禁：对话完成建模到后处理闭环

日期：2026-10-28。状态：验收设计，未实施/未运行。此门禁优先于此前“14操作、HOM控制或只读服务即可发布首版”的阶段定义。总体仍按[COMSOL功能对齐](comsol-mcp-functional-alignment.md)推进；首阶段先打通一条有真实产物的纵向闭环，不要求一次覆盖全部几何/物理模块。

## 1. 用户可见完成标准

用户通过自然语言指示真实MCP宿主，AI使用CST MCP完成：**创建工程 → 建立参数化模型 → 设置材料/边界/网格/求解 → 实际计算 → 后处理 → 输出结果与工件 → 正常收尾**。

验收中不得由开发者手写工程专用脚本、预先准备已建好的.cst、手动进入CST补设置或点击后处理来补齐链条。服务内部用已审查的官方接口/VBA实现操作是允许的；演示文件和预生成结果不能替代本次计算。用户必要的澄清、授权和宿主审批可以存在，不以“单句零确认”作为目标。

工具目录/Schema可被宿主发现、成功受理命令或Start返回1都是中间证据，均不能单独通过首阶段。

## 2. 首个验收场景：参数化真空Pillbox本征模

固定使用一个新的受控工作目录，CST版本/安装来源明确，背景PEC、内部真空圆柱腔，R=100mm、L=100mm；圆柱轴Z，参数和表达式进入工程定义。所有有持久性要求的模型/设置必须可通过历史重建保持。具体CST实体/背景建模路线须根据官方帮助冻结，不能把文字描述直接当作几何实现已正确。

计算采用Eigenmode、小网格、nmodes=1，初始频段500–2000MHz；这是单次仿真，不是HOM窗口扫描。若所选求解方法的实际频段语义不同，需在设计和配置读回中解释，不靠名称推断。网格密度在运行前确定并记录；正常求解不设总时长上限。

示例对话任务：

> 在指定目录新建一个真空Pillbox腔，半径100mm、长度100mm、轴向Z、PEC边界。用小网格计算500–2000MHz范围内的首个本征模，输出频率和沿中心Z轴、beta=1的R/Q，保存工程、结果表和诊断摘要，完成后正常关闭本任务CST实例。

用户没有给出版本、边界或结果定义等必要信息时，AI查询可用能力或澄清；不得替用户猜测会改变物理问题的设置。示例中的数值用于可复现验收，不硬编码进几何工具；同一模型构造接口必须允许不同半径/长度。

GUI/CLI/MCP使用相同模型/操作/服务；首阶段无需给每个底层编辑操作都设计独立GUI面板，但不能实现仅MCP可用的第二套建模后台。CLI和公共服务测试必须可以重放同一业务请求，确认模型定义和结果来源相同。
