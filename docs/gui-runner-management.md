# GUI后台Runner管理

2026-10-20新增。主窗口状态栏的“后台管理”打开当前项目的非模态管理窗口，沿用现有Qt主题；不是全机器进程管理器。

## 操作与边界

- 自动查看状态、实例ID、PID、后台源码根目录/Python、当前GUI源码目录、会话安全、项目状态、运行ID、日志位置和异常。路径可以选择复制。源码目录相同不证明文件版本完全相同，不能作为二进制或提交哈希校验。
- “连接/启动”：显式重新连接当前项目；不存在服务且OS所有权可获得时才启动。不会提交计算或自动续跑。活跃任务期间不可重置连接；通信未知时可显式重连，但无法取得所有权的后台不会被替换。
- “申请控制权”：沿用租约检查；其他窗口仍持有有效控制权时会拒绝，不抢占。
- “停止计算…”、“恢复检查…”：复用主窗口已有确认和标准收尾，不引入另一套停止协议。
- “退出后台…”：默认取消的确认后异步请求shutdown，并在最多10秒内核验Runner OS所有权释放；不强杀进程、不删除工件。请求等待不阻塞GUI。收到退出响应本身不算完成；响应丢失时仍检查所有权，未释放则报退出未确认。
- 成功退出后保持离线，不轮询重启；主窗口运行入口禁用。只有明确点击“连接/启动”或选择另一个项目才建立新连接。
- 运行/收尾中、状态未知、需要恢复或只读时禁止退出；服务端也保留相应门禁，防止检查后状态变化产生竞态。
- 关闭管理窗口仅隐藏窗口。2026-10-25主GUI已明确提供仅关界面与停止任务并退出后台及界面，详见[完整退出](gui-exit-resource-cleanup.md)；管理窗口仍复用同一个request_shutdown门禁。

## 旧包兼容与升级

新Runner快照增加runtime（pid/python/source_root）。旧版没有这些字段时显示“旧版未提供”，不能根据GUI目录猜后台版本。旧后台可能继续来自旧源码包，这是GUI重新连接已有独立服务的正常结果；需要先安全退出再连接新版。

旧版服务如果因RECOVERY_REQUIRED拒绝shutdown，GUI会保留错误及恢复入口，不能通过客户端绕过旧服务安全门禁。当前不提供强退、热替换、自动升级或自动重启功能，也不影响其他用户CST。
