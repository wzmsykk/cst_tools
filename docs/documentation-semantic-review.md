## 阅读与维护规则

1. 当前状态只概括能力/边界，TODO只保留现行动作；逐轮过程写有日期的验收/知识库，不继续在入口末尾追加“最新/当前真正下一步”。
2. current-reference只对定义的范围负责；design-reference中API/Schema/字段可能是候选，生产以源码和data契约为准。dated记录的“未实现/未提交/已退出”仅属于原时点。
3. documents[].review区分源码对照与适用性审查，记录具体checked_sources、问题ID和未核边界。文档角色已分类不表示原始数据仍在或历史性能/物理结论已复算。
4. 原厂/论文/社区固定来源只按原记录引用，本次未重新联网逐源核实；vendor/冻结夹具不修改。不把样本观察或第三方实现称为CST/COMSOL通用保证。
5. 实现新增/改动同批复审对应当前文档与定位映射；不通过反复加“后续以新页为准”来掩盖同页操作矛盾。
